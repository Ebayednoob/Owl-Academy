Creating a Manifold

The Snail Sigil

Welcome to the advanced module on Topological Design. In this tutorial, we will explore the concept of "creating a manifold" using the Symmetrical High-Density Continuous Curve Polygon (SHD-CCP) language.

In SHD-CCP, a "manifold" is a continuous, unbroken curve that defines both the boundary and internal structure of a sigil without self-intersection. The pen never lifts.

Phase 1: The Base Arc

We start with the underbelly. To maintain continuity, the tail cannot be a sharp, detached point. It must be a tight fold where the line reverses direction.

BeginPath(Origin) CurveTo(Right, sweep="shallow") Node(Front_Anchor) // Trace back for the tail fold CurveTo(Left_Down, angle="acute") CurveTo(Up_Right, tight_fold=true)

Phase 2: Inward Attenuation

The core challenge: creating a spiral with a continuous line. The line must spiral inward, becoming denser (attenuation). We use a Node Terminus jump here to reset our path for the head while maintaining visual weight.

Node(Shell_Start) GenerateSpiral( center=(X, Y), rotations=1.8, direction="inward" ) TerminatePath(Center_Node) // Jump back to Front_Anchor

Phase 3: Asymmetric Protrusions

We balance the heavy left-side shell with the delicate structures on the right. The eyes are formed by localized, high-density inner folds (loops).

ResumePath(Front_Anchor) // Lower Eye CurveTo(Up_Forward) CreateLoop(density="high") // Upper Eye CurveTo(Up_Back) CreateLoop(density="high") // Close Manifold CurveTo(Shell_Start, merge=true)

Student Exercise

Notice how the visual weight shifts. Your task: Try to conceptually eliminate the Node Jump at the center of the shell by imagining a "Double Spiral" where the line travels in, turns, and travels back out without intersecting itself.
